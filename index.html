1. Коротка інформація про ОС GNU/Linux

GNU/Linux — сімейство вільних Unix-подібних операційних систем, побудованих на ядрі Linux та системних програмах проєкту GNU. Вихідний код системи відкритий: його можна вільно використовувати, вивчати, змінювати та поширювати.

Історія

  • 1983 — Річард Столлман оголошує проєкт GNU зі створення вільної Unix-подібної ОС;
  • 1985 — засновано Фонд вільного програмного забезпечення (FSF), з'являється ліцензія GNU GPL;
  • 1991 — фінський студент Лінус Торвальдс публікує першу версію ядра Linux;
  • 1992 — ядро Linux переходить на ліцензію GPL, і поєднання GNU + Linux дає повноцінну вільну ОС;
  • 1993 — з'являються перші великі дистрибутиви: Slackware та Debian.

Складові системи

  • Ядро (kernel) — керує процесором, пам'яттю, пристроями, процесами;
  • Оболонка (shell) — командний інтерпретатор, найпоширеніший — bash;
  • Системні утиліти GNU — ls, cp, grep, компілятор gcc тощо;
  • Графічне середовище (необов'язково) — GNOME, KDE Plasma, Xfce;
  • Менеджер пакетів — встановлення програм: apt, dnf, pacman.

Де використовується

Linux працює на більшості серверів інтернету, на всіх суперкомп'ютерах зі списку TOP500, у хмарних сервісах, вбудованих пристроях, роутерах, а також є основою ОС Android.

Переваги: безкоштовність, відкритий код, стабільність, безпека, гнучке налаштування, потужний командний рядок та величезна спільнота.

2. Найпопулярніші дистрибутиви Linux

Дистрибутив — це готова до встановлення збірка ОС: ядро Linux + утиліти + менеджер пакетів + набір програм.

Ubuntu

Основа: Debian · пакети: apt / .deb

Найпопулярніший дистрибутив для початківців, робочих станцій і серверів. Розробник — Canonical.

Debian

Незалежний · пакети: apt / .deb

Один з найстаріших (1993) і найстабільніших дистрибутивів, основа для Ubuntu, Mint, Kali.

Linux Mint

Основа: Ubuntu · пакети: apt / .deb

Зручний для тих, хто переходить з Windows; середовище Cinnamon.

Fedora

Основа: Red Hat · пакети: dnf / .rpm

Сучасні технології та свіже ПЗ, спонсор — Red Hat.

Arch Linux

Незалежний · пакети: pacman

Мінімалістичний rolling-release дистрибутив для досвідчених користувачів.

Red Hat Enterprise Linux

Комерційний · пакети: dnf / .rpm

Корпоративний серверний дистрибутив з комерційною підтримкою.

openSUSE

Незалежний · пакети: zypper / .rpm

Зручний інструмент налаштування YaST; версії Leap і Tumbleweed.

Kali Linux

Основа: Debian · пакети: apt / .deb

Спеціалізований дистрибутив для тестування безпеки та кібербезпеки.

4. BASH-скрипт: імітація авторизації в системі

Скрипт імітує текстовий вхід у систему, як у консолі Linux (login: / Password:):

  • паролі зберігаються не у відкритому вигляді, а як хеші SHA-256;
  • пароль вводиться приховано (read -s);
  • дається 3 спроби, після чого доступ блокується на 5 секунд зі зворотним відліком;
  • після входу відкривається міні-сесія з меню та командою logout.

Тестові акаунти: admin / admin123 та student / linux2026.

⬇ Завантажити auth.sh
auth.sh
#!/bin/bash
# =====================================================
#  ПР 23. Вступ у Bash — імітація авторизації в системі
#  Запуск:  chmod +x auth.sh && ./auth.sh
#  Тестові акаунти:  admin / admin123,  student / linux2026
# =====================================================

# ---------- Кольори ----------
RED='\033[1;31m'
GREEN='\033[1;32m'
YELLOW='\033[1;33m'
CYAN='\033[1;36m'
NC='\033[0m'

# ---------- "База" користувачів: логін -> SHA-256 хеш пароля ----------
# Паролі не зберігаються у відкритому вигляді, лише їхні хеші
declare -A USERS=(
    [admin]="240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9"   # admin123
    [student]="c4f9fa0b227bd46a37bf49b6f56d8b8750b7e46d39d79654f440e139916d8581" # linux2026
)

MAX_ATTEMPTS=3      # кількість спроб входу
LOCK_TIME=5         # секунд блокування після невдалих спроб

# ---------- Функція: хешування пароля ----------
hash_password() {
    printf '%s' "$1" | sha256sum | cut -d' ' -f1
}

# ---------- Функція: заголовок ----------
banner() {
    clear
    echo -e "${CYAN}=========================================${NC}"
    echo -e "${CYAN}   GNU/Linux $(uname -r 2>/dev/null)${NC}"
    echo -e "${CYAN}   $(hostname 2>/dev/null) login — $(date '+%d.%m.%Y %H:%M')${NC}"
    echo -e "${CYAN}=========================================${NC}"
}

# ---------- Функція: сесія після входу ----------
session() {
    local user=$1
    echo -e "\n${GREEN}Вхід виконано успішно. Вітаємо, ${user}!${NC}"
    echo -e "Останній вхід: $(date '+%a %d %b %Y %H:%M:%S')"
    echo
    while true; do
        echo -e "${YELLOW}1${NC} — інформація про користувача"
        echo -e "${YELLOW}2${NC} — поточна дата і час"
        echo -e "${YELLOW}3${NC} — вміст поточного каталогу"
        echo -e "${YELLOW}0${NC} — вийти із системи (logout)"
        read -p "${user}@system:~\$ " cmd
        case $cmd in
            1) echo -e "Користувач: ${GREEN}${user}${NC}, роль: $([[ $user == admin ]] && echo адміністратор || echo користувач)" ;;
            2) date ;;
            3) ls ;;
            0) echo -e "${CYAN}logout. Сеанс користувача ${user} завершено.${NC}"; return ;;
            *) echo -e "${RED}Невідома команда${NC}" ;;
        esac
        echo
    done
}

# ---------- Головна логіка авторизації ----------
banner
attempt=1
while (( attempt <= MAX_ATTEMPTS )); do
    read -p "login: " username
    read -s -p "Password: " password     # -s — пароль не відображається
    echo

    if [[ -z $username || -z $password ]]; then
        echo -e "${RED}Логін і пароль не можуть бути порожніми.${NC}"
    elif [[ -n ${USERS[$username]} && ${USERS[$username]} == "$(hash_password "$password")" ]]; then
        session "$username"
        exit 0
    else
        left=$(( MAX_ATTEMPTS - attempt ))
        echo -e "${RED}Login incorrect.${NC} Залишилось спроб: ${left}"
    fi
    (( attempt++ ))
    echo
done

# ---------- Блокування після невдалих спроб ----------
echo -e "${RED}Забагато невдалих спроб! Доступ заблоковано на ${LOCK_TIME} с.${NC}"
for (( i = LOCK_TIME; i > 0; i-- )); do
    printf "\rРозблокування через %d с... " "$i"
    sleep 1
done
echo -e "\n${YELLOW}Спробуйте запустити скрипт ще раз.${NC}"
exit 1

Запуск

bash
student@linux:~$ chmod +x auth.sh   # дозвіл на виконання
student@linux:~$ ./auth.sh
login: student
Password:
Вхід виконано успішно. Вітаємо, student!
